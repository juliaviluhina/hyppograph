# Contract: shared modules + workflow inlined copy + drift guard

Feature 001's pipeline helper logic and `agent()` prompt text move into shared modules that the evals
import directly. The `Workflow`-tool sandbox forbids `import` (`// no imports in the sandbox`), so the
workflow keeps a generated inlined copy and a guard test enforces byte-identity (FR-002, FR-007a).

## Modules (source of truth) — `.claude/workflows/lib/`

### `intake-core.mjs`

Named exports, pure and dependency-free:

`titleKey`, `companyKey`, `slug`, `stableHash`, `foldSet`, `dedupKey` (the
`companyKey--titleKey--locKey` assembly), `criteriaFingerprint`, `noTriageCriteria`,
`effectiveExcludedLocations`, `completenessLevel` (the low-completeness threshold rule),
`renderSummary`, `newRunSummary`, `bumpReason`, `provenanceLine`, `trackedBoardsToSources`.

Contract: no `import`, no I/O, no `Date.now()`, deterministic for a given input. These are the
functions `evals/component/*.test.mjs` assert on.

### `prompts.mjs`

One named export per model-backed subtask, each a string (or a `(vars) => string` builder):
`preTriagePrompt`, `extractionPrompt`, `enumeratePrompt`, `sourceListPrompt`. The text is exactly
what the pipeline sends — the per-component evals import these, never a copy (FR-007).

## Workflow inlined copy — `.claude/workflows/intake-normalize.js`

Each region is delimited:

```js
/* BEGIN inlined:intake-core — generated from .claude/workflows/lib/intake-core.mjs, do not edit here */
function titleKey(roleTitle) { /* … identical body … */ }
// …
/* END inlined:intake-core */
```

Rules:
- The body between the markers equals the module's content with `export ` prefixes removed and any
  `import` lines dropped — nothing else changes.
- Regenerated by copying from the module, never hand-edited.
- Behaviour of the workflow is unchanged by the extraction: an `integration` gate run before and
  after produces the same expected tree.

## Drift guard — `evals/component/drift.test.mjs`

For each region (`intake-core`, `prompts`):
1. Read the module, strip `export `/`import` lines, normalise trailing whitespace.
2. Read the marker-delimited region from `intake-normalize.js`.
3. Assert byte-identity. On failure, print a unified diff and name the region (US1 scenario 2).

Runs in the free `component` layer — no model, no network, part of `node --test`.
